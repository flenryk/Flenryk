# Flenryk

**The world isn't incomplete. It's disconnected.**

I build systems that connect what already exists — people, data, technology —
and that stay in production long after the demo.

Geospatial platforms for public decision-making. Pipelines that replaced
nightly exports with continuous sync. Neural classifiers that removed manual
triage from citizen communications.

**Built slowly, to last.**

Core tools: Python · TypeScript · Go · Rust · Flutter ·  PyTorch · FastAPI · React · PostgreSQL

The cases, with the architecture decisions behind them: [flenryk.com](https://flenryk.com)
